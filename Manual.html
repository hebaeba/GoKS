Go棋譜Studio 使い方

起動と画面

ZIPをすべて展開し、GoKifuStudio.exeを起動します。enginesフォルダーをEXEの隣に置いてください。左側は棋譜操作とグラフ、中央は碁盤、右側は解析・対局等のメニューです。日本語／Englishで表示言語を切り替えます。

棋譜を開く・保存する

「棋譜を開く」でファイルを選ぶか、盤面へドラッグします。SGFなどをクリップボードへコピーしてCtrl+Vでも読み込めます。文字化けは「棋譜欄」の文字コードを確認します。「保存・印刷」または「保存」から「棋譜全体を保存」を選ぶと変化・コメントを含む棋譜を保存できます。未保存内容を失う操作では確認が出ます。

編集と変化

棋譜ロックを外して交点をクリックすると着手します。途中から別の手を打つと変化を作れます。手順・ツールで黒白の配置石、記号、文字、網掛けを指定できます。取り消し／やり直しで編集を戻せます。削除は表示中の着手とその先を削除します。

手順移動

↓／↑または盤上のホイールで1手進む／戻る、Shift+↓／↑で10手移動します。Homeは初手前、Endは現在の手順の末尾です。自動再生は現在の手順を進み、末尾で停止します。Mは手数、Cは座標の表示切替、Oは棋譜を開く、Ctrl+Homeは碁盤クリアです。文字入力やダイアログは入力を優先します。

画像から局面を取り込む

「画像から」で画像を選択・貼り付け・ドラッグし、盤面範囲と四隅を指定して認識します。認識結果の石をクリックして修正し、黒白の個数を確認してください。置き石、コミ、手番、取られた石を設定し、確認してから取り込みます。1枚の画像から元の着手順・コウ履歴は復元できません。

エンジンと解析

「エンジン」でKataGoのEXE・モデル・CFGを登録します。登録ファイルを移動・削除すると起動できません。解析を開始／Spaceで現在局面を解析します。候補手へマウスを重ねると読み筋を表示し、F2で第一候補を着手できます。網掛け限定は着手候補を網掛け内へ制限します。盤外の石を無視する機能ではありません。

全局解析とグラフ

全局解析で1局面の時間を選び、開始します。中断・再開ができます。結果を保存すると後で再読込みできます。ランキングは黒白別に表示し、10位より下を折りたたみます。グラフの横軸は手数（数字）、縦軸は勝率と目数差です。未解析部分は空白です。AI同士の対局では黒番AIの黒勝率と白番AIの白勝率を黒白の線で分け、目数差も各AIの自分視点で表示します。

対局

黒番・白番に人間またはKataGoを選び、互先／置碁／自由置碁、コミ、時間制限・訪問数を設定して開始します。AIの時間と訪問数は先に達した方で着手します。両方を無制限にすると着手を待ち続ける場合があります。中断で思考を停止し、再開で続けます。人間側には待ったがあります。互先の投了初期条件は3%以下が自身の手番で3回連続、序盤の禁止は0手です。置碁では投了許可／不許可を選びます。

推定値と地合い計算

推定値は解析用エンジンに現在局面を評価させます。対局中は対局を中断して計算します。推定は確定した結果ではありません。地合い計算は双方の境界が確定した終局後に使用し、死に石・セキ・アゲハマを確認します。読込み棋譜でも使えますが、境界が未確定なら正しい終局計算にはなりません。

画像・印刷・GIF

保存メニューから盤面画像、盤面を無色で保存、印刷、手順GIFを選びます。GIFは範囲と表示条件を設定して作成・保存します。解析保存とSGF保存は別です。

表示・音

通常表示の右下「表示・音」、シンプル表示の「表示」→「表示・音」で設定窓を開きます。文字・碁盤背景・グラフ・石音の4項目です。変更はプレビューされ、適用で保存、キャンセルまたは窓を閉じると最後の保存内容へ戻ります。標準に戻す操作も適用が必要です。

文字と外観の範囲

文字は小12px・標準14px・大16px・特大18px。見出しは各2px大きく、補助表示は12／12／14／16pxです。日本語・英語のサイズとフォントを別々に保存します。盤上の数字・記号は80／100／120%。テーマ、色、模様、石の描画、グラフ線を選べます。大きい文字では折り返し・スクロールが増えることがあります。

画像と石音の登録

画像はPNG/JPEG/WebPの8MB以下、保存時に最大512pxへ縮小します。音声はWAVの1MB以下です。音量0は無音です。着手・手順移動・自動再生ごとにオンオフを選びます。読み筋のホバーでは鳴りません。独自の石音3種は合成音で、LizzieYzyの素材を使用していません。

シンプル表示と独立窓

シンプル表示は碁盤を大きく表示します。上部メニューから各機能を使えます。詳細メニュー、画像認識、地合い計算、推定値、表示・音はWindowsの独立窓として移動・サイズ変更できます。通常表示で隠した右側パネルの状態は切替時に保持します。

更新・不具合報告

更新前に棋譜と解析結果を保存してください。問題はバージョン、再現手順、エンジン名を添えて報告します。ログの個人名・端末内パス・IP・接続トークンを公開しないでください。ライセンスは同梱のLICENSE.txt、licenses.htmlを確認してください。

GoKifuStudio Manual

Start

Extract the entire ZIP and run GoKifuStudio.exe, keeping engines/ beside it. The left panel contains controls and graphs, the center is the board, and the right panel provides analysis and other tools. Choose Japanese or English in the language controls.

Open and save

Open a record, drag it onto the board, or paste SGF using Ctrl+V. For encoding problems use the Record tab. Save Entire Game includes variations and comments. Analysis JSON is saved separately from SGF.

Editing and navigation

Unlock the game before editing. A different move from an earlier position creates a variation. Use tools for setup stones, labels and shading. Undo/Redo restore edits. Up/Down and the mouse wheel step through moves; Shift+Up/Down moves ten steps, Home/End selects the first/final position. M toggles move numbers, C coordinates, O opens a game. Ctrl+Home clears after confirmation. Text input takes priority.

Image import

Choose, paste or drop an image, mark the visible board and its corners, recognize stones, and correct the result. Check stone counts, handicap, komi, next player and captured stones. A single image does not recover move order or ko history.

Analysis

Register a KataGo executable, model and CFG in Engine. Start Analysis or press Space. Hover over a candidate to preview its PV; F2 plays the top candidate. Shaded-only analysis restricts candidate moves to marked intersections; it does not ignore stones elsewhere. Full Game Analysis supports pause/resume and saving results. Rankings show ten rows per side initially.

Graphs

The horizontal labels are move numbers; the vertical axes show win rate and score. Missing results stay blank. AI–AI games use separate black/white win-rate lines from each AI’s own perspective; score estimates also retain each AI’s own perspective.

Games

Choose Human or KataGo for each side, set even/handicap/free-handicap conditions and limits, then start. AI search ends when either the time or visit limit is reached. Both unlimited can wait indefinitely. Pause stops game engines. Resume continues. Human sides can take back moves. Even-game resignation defaults to 3% for three own turns, with zero early protected moves. Handicap games offer Allow/Disallow resignation.

Estimate and scoring

Estimate uses the analysis engine; during a game it pauses play first. An estimate is not a final result. Score only after boundaries and required moves are settled. Confirm dead stones, seki and prisoners. Loaded records allow scoring, but unresolved boundaries still require human judgment.

Images and GIF

The Save menu includes board images, monochrome export, print and GIF. Set the range before creating a GIF. The monochrome export does not alter the displayed board.

Appearance & Sound

Open the footer control or View → Appearance & Sound in Simple View. The independent window has Text, Board/Background, Graph and Sound tabs. Changes preview immediately. Apply saves, while Cancel or closing restores saved settings. Reset Defaults also requires Apply.

Text settings

Body text is 12/14/16/18px, prominent text 14/16/18/20px, help text 12/12/14/16px. Japanese and English remember sizes and font families separately. Choose or type an installed font name; unavailable fonts fall back. Board labels scale 80/100/120%. Large text may wrap or require scrolling.

Themes and audio

Choose colors, board texture and stone style, and graph colors/line width. Images must be PNG/JPEG/WebP up to 8 MB, resized to at most 512px for storage. WAV files must be up to 1 MB. Volume zero is silent. Played moves, navigation and autoplay are separate options; PV hover is silent. The three bundled synthesized sounds are original and do not use LizzieYzy assets.

Simple View and windows

Simple View enlarges the board and exposes tools through the top menus. Detailed panels, image import, scoring, estimates and appearance use independent movable/resizable Windows windows.

Support and terms

Save records and analysis before upgrading. Include version, reproduction steps and engine name in reports. Remove personal information, paths, IP addresses and connection tokens from logs. See LICENSE.txt and licenses-en.html for terms.
