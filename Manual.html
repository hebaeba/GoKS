Go棋譜Studio 使い方

起動と画面

ZIPをすべて展開し、GoKS.exeを起動します。起動時にWindowsの警告が出る場合は、GoKS.exeを右クリックして最下部にあるプロパティをクリックし、下部の「許可」をチェックしておけば警告は消えます。KataGoエンジンは同梱していません。棋譜編集と人間同士の対局はエンジンが無くても使えます。左側は棋譜操作とグラフ、中央は碁盤、右側は解析・対局等のメニューです。日本語／Englishで表示言語を切り替えます。

KataGoの登録（任意）

「エンジン」メニュー先頭の「CPU版エンジンを自動セットアップ」を選びます。確認後、GoKS.exeの隣のkatagoフォルダーへKataGo Eigen v1.18.1とモデルを取得・配置します。各工程の進行状況が表示され、完了するとエンジンリストへ自動登録されます（「リストに追加」は不要です）。既存のkatagoフォルダーがある場合はバックアップを保存してから入れ替えます。保存できない場合はGoKSを自分が書き込める場所へ移すか、手動登録を選んでください。

手動登録

「エンジン」から「個別ダウンロード」を開きます。「CPU版エンジンを入手」でKataGo Eigen v1.18.1を入手したらZIPを展開します。「CPU版モデルを入手」で取得した.gzを解凍せず、そのフォルダーまたはmodels内に置きます。エンジンリスト下の「新規」から「エンジンの名前」を記入、「エンジン」「モデル」「設定CFG」を欄の右端にある「参照」から指定してください。記入・指定されたら「リストに追加」を押します。「設定CFG」は空欄でも構いません。エンジン名右の「起動時」ラジオボタンにチェックするとGoKS.exeの起動時に自動起動します。

CPU版エンジン ／ CPU版モデル

エンジン・モデルの更新

CPU版エンジンは固定で、自動更新しません。エンジンを更新するにはKataGo公式リリースから新しいWindows版ZIPを入手し、既存のkatagoとは別のフォルダー（例：katago-new）に展開します。使うモデル（拡張子.gzのファイル）をその中のmodelsに置き、「エンジンリスト」で別名登録してください。モデルだけ更新する場合は公式モデル一覧からNetwork Fileを入手し、元のモデルとは別名でmodelsに置きます。「新規」でエンジン(katago.exe)と新しいモデル（拡張子.gzのファイル）を登録します。

KataGo releases · KataGo networks

棋譜を開く・保存する

「棋譜を開く」でファイルを選ぶか、盤面へ棋譜ファイルをドラッグします。棋譜ファイルをコピーしたら盤面上で右クリックまたはCtrl+Vキーを押しても読み込めます。文字化けしたら「棋譜欄」の文字コードを確認します。「保存・印刷」または「保存」から「棋譜全体を保存」を選ぶと変化・コメントを含む棋譜を保存できます。未保存内容を失う操作では確認が出ます。

編集と変化

棋譜ロックを外して碁盤の交点をクリックすると着手します。途中から別の手を打つと変化を作れます。手順・ツールで黒白の配置石、記号、文字、網掛けを指定できます。取り消し／やり直しで編集を戻せます。削除は表示中の着手とその先を削除します。

手順移動

↓／↑またはマウスホイールで1手進む／戻る、Shift+↓／↑で10手移動します。Homeは初手前、Endは現在の手順の末尾です。自動再生は現在の手順を進み、末尾で停止します。Mは手数、Cは座標の表示切替、Oは棋譜を開く、Ctrl+Homeは碁盤クリアです。文字入力やダイアログは入力を優先します。

画像から局面を取り込む

「画像から」で画像を選択・貼り付け・ドラッグし、盤面範囲と四隅を指定して認識します。認識結果の石をクリックして修正し、黒白の個数を確認してください。置き石、コミ、手番、取られた石を設定し、確認してから取り込みます。画像から元の着手順・コウ履歴は復元できません。

エンジンと解析

「エンジン」でKataGoのEXE・モデル・CFGを登録します。登録したファイルをその後に移動・削除すると起動できません。解析を開始(Space)で現在局面を解析します。候補手へマウスを重ねると読み筋を表示し、F2キーを押すと第一候補を着手します。［網掛け領域内だけ解析］は着手候補を網掛け内へ制限します。網掛けで囲った内部で右クリックすると、内部全域に網がかかります。KataGoは網掛け外の石も認識しています。

全局解析とグラフ

全局解析で1局面毎の解析時間を選び、開始します。中断・再開ができます。結果を保存すると後で再読込みできます。ランキングは黒白別に表示し、10位より下を折りたたみます。グラフの横軸は手数（数字）、縦軸は勝率と目数差です。未解析部分は空白です。AI(KataGo)同士の対局では黒勝率と白勝率を黒白の線で分け、目数差も各AIの自分視点で表示します。

対局

黒番・白番に人間またはKataGoを選び、互先／置碁／自由置碁、コミ、時間制限・訪問数を設定して開始します。KataGoは時間制限と訪問数のどちらかが先に達した時に着手します。両方を無制限にすると着手を待ち続ける場合があります。中断で思考を停止し、再開で続けます。人間側には待ったがあります。互先でのAIの投了条件は勝率X%以下が自身の手番で3回連続したときとします。Xの初期値は3%です。KataGoの序盤での投了を何手まで禁止と設定できます。初期値は0手です。置碁では投了許可／不許可を選べます。

対局時計

人間側の「方式」を選び、必要な欄だけを入力します。

  • 切れ負け：持ち時間30分が初期値で、時間を使い切ると負けです。
  • 秒読み：持ち時間（分）30、秒読み（秒／回）30／5が初期値です。持ち時間後は秒読みとなり、時間内に着手すればその1回分を戻します。使い切った回数は戻らず、最後も使い切ると切れ負けです。
  • フィッシャー：初期値は30分、1手ごとに10秒加算。合法な着手・パス後に加算し、時間が切れると負けです。ここでは上限は設定していません。
  • カナダ：初期値は持ち時間0分・区間10分・15手。最初から10分以内に15手を打つ設定です。達成すると次の10分・15手へ戻り、余り時間は繰り越しません。持ち時間を設定した場合、その終了後に区間制へ移ります。

方式は「切れ負け・秒読み・フィッシャー・カナダ・無制限」の順です。無制限では時間切れになりません。時計の別窓は移動・サイズ変更できます。位置とサイズは次回も同じになります。モニター構成が変わった場合は画面内へ調整します。本体を最小化すると時計も隠れ、本体を戻すと再表示されます。閉じても計時は続きます。「対局時計」で再表示します。中断・推定値の計算・着手確認中は停止します。待ったで使った時間は返しません。取り消した手による加算時間・区間更新も取り消し、時間が尽きれば切れ負けです。秒読み中は毎秒、他方式は残り10秒から音が鳴ります。残り1秒と秒読みの最後の1回は音を強め、「警告音」で消音できます。KataGoには従来の時間・訪問数制限を使います。

推定値と地合い計算

推定値は解析用エンジンに現在局面を評価させます。対局中は対局を中断して計算します。推定は確定した結果ではありません。地合い計算は双方の境界が確定した終局後に使用し、死に石・セキ・アゲハマを確認します。読込み棋譜でも使えますが、境界が未確定なら正しい終局計算にはなりません。

画像・印刷・GIF

保存メニューから「盤面画像」、「盤面を無色で保存」、「印刷」、「手順GIF」を選びます。GIFは範囲と表示条件を設定して作成・保存します。解析保存と棋譜の保存は別です。

表示・音

通常表示の左パネル「表示・音」、シンプル表示の「表示」→「表示・音」で設定窓を開きます。文字・碁盤背景・グラフ・石音の4項目です。変更はプレビューされ、「元に戻す」または「閉じる」で未保存の変更を戻します。「標準に戻す」は現在の項目だけを戻し、他の項目は維持します。変更を確定する場合は「保存」を押します。「文字」は現在の言語の文字設定と盤上の数字・記号が対象です。

文字と外観の範囲

文字は小12px・標準14px・大16px・特大18px。見出しは各2px大きく、補助表示は12／12／14／16pxです。日本語・英語のサイズとフォントを別々に保存します。盤上の数字・記号は80／100／120%。テーマ、色、模様、石の描画、グラフ線を選べます。大きい文字では折り返し・スクロールが増えることがあります。

画像と石音の登録

画像はPNG/JPEG/WebPの8MB以下、保存時に最大512pxへ縮小します。音声はWAVの1MB以下です。音量0は無音です。着手・手順移動・自動再生ごとにオンオフを選びます。読み筋のホバーでは鳴りません。独自の石音3種は合成音です。

シンプル表示と独立窓

シンプル表示は碁盤のみを表示します。上部メニューから各機能を使えます。詳細メニュー、画像認識、地合い計算、推定値、表示・音はWindowsの独立窓として移動・サイズ変更できます。通常表示では左右のパネルを表示します。

更新・不具合報告

更新前に棋譜と解析結果を保存してください。不具合はバージョン、再現手順、エンジン名を添えて報告します。ログの個人名・端末内パス・IP・接続トークンを公開しないでください。ライセンスは同梱のLICENSE.txt、licenses.htmlを確認してください。

GoKifuStudio User Manual

Starting the application and screen layout

Extract the entire ZIP and run GoKS.exe. If Windows displays a security warning, right-click GoKS.exe and open Properties; when an Unblock option is offered at the bottom of the dialog, select it to remove the warning for this file. KataGo is not included. You can edit game records and play human-versus-human games without an engine. The left panel contains record controls and graphs, the center contains the board, and the right panel contains Analysis, Play, and other menus. Switch the display language between Japanese and English.

Registering KataGo (optional)

From the Engine menu, select CPU engine automatic setup. After confirmation, GoKS downloads KataGo Eigen v1.18.1 and a model and installs them in the katago folder beside GoKS.exe. Progress is displayed for each stage, and the engine is registered automatically when setup finishes; you do not need to click Add to List. If a katago folder already exists, the installer backs it up before replacing it. If GoKS cannot write to the folder, move GoKS to a writable location or use manual registration.

Manual registration

Open Individual downloads in the Engine menu. Choose Get CPU engine to download KataGo Eigen v1.18.1, then extract the ZIP. Choose Get CPU model and place the downloaded .gz file, without decompressing it, alongside the engine or in its models folder. Under Engine List, select New and enter an Engine name. Use Browse at the right of the Engine, Model and Config CFG fields to select the appropriate files, then click Add to List. Config CFG may be left empty. To launch an engine automatically when GoKS.exe starts, select the Startup radio button beside its name.

CPU engine / CPU model

Updating the engine or model

The CPU engine version used by automatic setup is fixed and does not update itself. For a newer engine, download the latest Windows ZIP from the official KataGo releases and extract it into a separate folder, such as katago-new, instead of the existing katago folder. Put the model (.gz) in its models folder and register the engine under a different name in Engine List. To update only the model, download the Network File from the official model catalog, save it under a different filename in models, and use New to register the existing katago.exe with the new model.

KataGo releases · KataGo networks

Opening and saving game records

Choose Open Game to select a file, or drag a game record file onto the board. You can also copy a record file and paste it by right-clicking the board or pressing Ctrl+V. If text is garbled, check the encoding in the Record panel. Choose Save Entire Game from Save / Print or Save to include variations and comments. An operation that would discard unsaved changes asks for confirmation.

Editing and variations

Unlock the record and click an intersection to play a move. Playing a different move from an earlier position creates a variation. Moves / Tools provides black and white setup stones, symbols, text, and shading. Undo / Redo reverses edits. Delete removes the displayed move and its continuation.

Moving through a game

Down / Up or the mouse wheel moves forward / backward one move; Shift+Down / Up moves ten moves. Home goes before the first move, and End goes to the end of the current line. Autoplay advances along the current line and stops at the end. M toggles move numbers, C toggles coordinates, O opens a record, and Ctrl+Home clears the board. Text inputs and dialogs take priority over shortcuts.

Importing a position from an image

Under From Image, choose, paste, or drag an image and specify the board area and four corners for recognition. Click any incorrectly recognized stones to correct them and check the black and white counts. Set handicap stones, komi, player to move, and captures before confirming the import. The original move order and ko history cannot be reconstructed from a single image.

Engines and analysis

Register KataGo's executable, model, and optional CFG under Engine. Moving or deleting registered files prevents the engine from starting. Start Analysis (Space) analyzes the current position. Hover over a candidate to see its principal variation; F2 plays the top candidate. Analyze Shaded Region Only restricts candidate moves to the shaded region. Right-clicking inside a closed shaded boundary fills the enclosed area; stones outside the shaded region are still taken into account.

Full-game analysis and graphs

In Full Game Analysis, choose an analysis time per position and start; you can pause and resume. Save the results to reload them later. Rankings are displayed separately for Black and White; ranks below the top ten are collapsed. The horizontal graph axis contains move numbers, and the vertical axes show win rates and score differences. Unanalyzed positions are left blank. In KataGo-versus-KataGo games, Black and White win rates are shown as separate lines, and score estimates are shown from each AI's perspective.

Playing a game

Select Human or KataGo for Black and White, choose an even game, handicap, or free handicap, and set komi and time / visit limits before starting. KataGo plays when either the time limit or visit limit is reached first. Setting both to unlimited may cause it to keep thinking. Pause stops thinking and Resume continues. Human players can take back moves. In an even game, automatic AI resignation occurs when its win rate stays at or below X% for three consecutive turns by that AI; X defaults to 3%. You can prevent resignation for a specified number of opening moves (default 0). In handicap games, choose whether resignation is permitted.

Game clock

Under a human player's System, choose one of the five clock modes and enter only the relevant values.

  • Absolute: the default main time is 30 minutes; using it all loses the game.
  • Byo-yomi: the defaults are 30 minutes main time, 30 seconds per period, and 5 periods. After main time runs out, moving within the period resets that period; exhausted periods do not return, and exhausting the last period loses the game.
  • Fischer: defaults to 30 minutes with an additional 10 seconds after each legal move or pass. Flagfall loses the game; there is no maximum clock time.
  • Canadian: defaults to zero minutes of main time, a 10-minute block, and a quota of 15 moves. You must play 15 moves in 10 minutes from the start. After the quota, another 10 minutes / 15 moves begins; unused time is not carried forward. Setting a main time delays the blocks until main time is exhausted.

The options are ordered Absolute, Byo-yomi, Fischer, Canadian, Unlimited. Unlimited has no timeout. The clock opens in an independent, movable and resizable window whose position and size are remembered. If the monitor setup changes, its window is moved back on-screen. Minimizing the main window hides the clock; restoring the main window shows it again. Closing the clock window does not stop time: reopen it with Game Clock. Time pauses during a game pause, estimate calculation, and move confirmation. Takeback does not refund elapsed time; increments and completed blocks earned by undone moves are also reversed, potentially causing flagfall. Byo-yomi beeps each second; the other systems beep during the last ten seconds. The last second and final byo-yomi period use a stronger sound; uncheck Clock sound to mute it. KataGo continues to use the usual search time and visit limits.

Estimates and scoring

Estimate asks the analysis engine to evaluate the current position, pausing an active game first. This estimate is not a confirmed result. Use Scoring after the game ends and both sides' boundaries are settled, checking dead stones, seki, and prisoners. Scoring can also be used with imported records, but unsettled boundaries cannot give a reliable final score.

Images, printing, and GIF

From Save, choose Board Image, Monochrome Board Image, Print, or Move GIF. Set the move range and display options before creating and saving a GIF. Saving analysis is separate from saving the game record.

Appearance and sound

Open Appearance & Sound from the left panel in Normal View or from View → Appearance & Sound in Simple View. There are four areas: text, board/background, graph, and stone sound. Changes are previewed. Revert or Close restores the last saved settings without saving changes. Reset defaults affects only the current area and preserves the others. Text applies to the current language and board numbers and symbols. Choose Save to keep your changes.

Text and appearance settings

Text sizes are Small 12px, Normal 14px, Large 16px, and Extra Large 18px. Headings are 2px larger; auxiliary text uses 12 / 12 / 14 / 16px. Japanese and English text sizes and fonts are stored separately. Board numbers and symbols scale to 80%, 100%, or 120%. Choose themes, colors, textures, stone styles, and graph lines. Large text can increase wrapping and scrolling.

Adding images and stone sounds

Images must be PNG/JPEG/WebP files up to 8 MB and are resized to at most 512px for storage. Sounds must be WAV files no larger than 1 MB. Volume 0 is silent. Sound can be enabled separately for moves, navigation, and autoplay, but not for hovering over a variation. The three original built-in stone sounds are synthesized.

Simple View and independent windows

Simple View shows only the board; the top menus remain available. Detailed menus, image recognition, scoring, estimates, and appearance/sound settings open in independent Windows windows that can be moved and resized. Normal View displays the left and right panels.

Updates and reporting problems

Save your game records and analysis results before updating. For a bug report, include the version, steps to reproduce, and engine name. Do not publish names, local paths, IP addresses, or connection tokens from logs. Consult the included LICENSE.txt and license notices.
