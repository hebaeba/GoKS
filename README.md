# Go棋譜Studio / GoKifuStudio

**バージョン 0.8.0-preview.3（更新102・公開前確認版）**

Windows PC向けの棋譜編集・KataGo解析・対局アプリです。日本語／英語、通常表示／シンプル表示に対応します。EXEとフォルダーの名称は `GoKifuStudio` です。

## 起動

Windows用ZIPをすべて展開し、`GoKifuStudio.exe` を起動します。EXEだけを移動せず、同梱する `engines` を同じ場所に置いてください。利用者によるNode.js・Rustの導入は不要です。内蔵エンジンはKataGo-Eigenです。

使い方は同梱の **Manual.html** を開いてください。日本語・英語を切り替えられます。

このZIPがソース版の場合、実行ファイルは含まれません。GitHub ActionsでWindowsビルドを実行し、生成された `GoKifuStudio-Windows` のArtifactsを取得します。Releasesの利用者向けZIPとGitHub自動生成の「Source code」は区別してください。

## 機能

- 棋譜の閲覧・編集、変化、コメント、置碁・自由置碁、盤上の記号。
- 棋譜・画像のファイル読み込み、ドラッグ、クリップボードからの取り込み。
- KataGoによる局面・全局解析、読み筋、グラフ、目数／勝率ランキング。
- 人間対AI・AI対AI・人間対人間の対局、中断・再開・待った。
- 推定値、終局後の地合い計算。
- SGF・解析結果の保存、盤面画像・印刷、手順GIF、一時保存。
- 文字・盤面・背景・グラフ・石音の変更。

## 文字・外観・音

画面下部の「表示・音」、またはシンプル表示の「表示」→「表示・音」で独立した設定窓を開きます。Windowsのタイトルバーで移動し、外枠でサイズを変えられます。

| 設定 | 範囲 |
|---|---|
| 通常文字 | 小12／標準14／大16／特大18px |
| 見出し・主要項目 | 14／16／18／20px |
| 補助表示 | 12／12／14／16px |
| 通常ボタンの高さ | 24／26／28／30px、内側余白3px |
| フォント | 端末内のフォント名を選択・入力 |
| 盤上の数字・記号 | 80／100／120%、盤面の大きさに連動 |
| テーマ | 木肌・白灰・夜。色の個別変更も可能 |
| 盤面・石 | 無地・木目・画像、立体・単色・画像 |
| グラフ | 色、線幅1～4px（0.5px刻み）、実線・破線 |
| 石音 | 独自合成音3種またはWAV、音量0～100% |

日本語と英語の文字サイズ・フォントは別々に保存します。大きな文字では折り返しやスクロールが増える場合があります。存在しないフォントは標準フォントで補います。フォントファイルは配布しません。

設定変更はプレビューされます。「適用」で保存、「元に戻す」または「閉じる」で未保存の変更を戻します。「適用」では窓を閉じません。「標準に戻す」も適用するまでは保存されません。着手・手順移動・自動再生の石音は個別に指定でき、読み筋へのマウスオーバーは無音です。

画像はPNG/JPEG/WebP・8MB以下（最大512pxへ縮小して保存）、音声はWAV・1MB以下です。ブラウザー版では、ユーザー操作前に音が再生できない場合があります。

グラフの下部は手数の数字のみを表示します。重ならないよう目盛りの文字を間引き、25手ごとの短い線と最終手数は残します。空盤など表示範囲が極端に狭い場合は表示可能な数を優先します。

## 更新101の設定操作

「表示・音」「キー操作」は左パネルにあります。表示・音は実際の画面に反映する設定です。「適用」で保存しても開いたままです。終了は右上の「閉じる」です。Windowsのインストール済みフォント一覧から選ぶか、フォント名欄へ入力してEnterを押します。取得できない場合も手入力できます。黒白の石は立体・単色・画像ごとに3種の見本から選べ、自分の画像も登録できます。

エンジンリスト右端のラジオボタンで次回の起動エンジンを指定します。登録件数の右の↑／↓は選択中のエンジンを移動します。起動指定の登録やファイルを削除した場合は警告を表示します。初期値は同梱KataGo-Eigenです。

## 更新102
- 同梱エンジンのパスを `./engines/katago/` 以下の相対パスで保存し、WindowsではGoKifuStudio.exeの位置から解決します。保存済みの同梱配置パスも移行します。外部エンジンの指定は維持します。
- 中断・待ったで対応するKataGoを再利用します。中断可能な探索命令に未対応の旧版は、思考中のみ再起動が必要です。
- 通常／シンプル表示の切替と幅変更時の配置を修正しました。
- 「画面背景」は本体の余白にも適用されるため「画面の余白色」に改称しました。木肌テーマを選ぶと薄い木目を適用し、碁盤色を維持します。

更新時はZIP内のフォルダー構成を維持してください。GitHubにはweb、src-tauri、backend、tests、scriptsとルートの文書・package.json・AGENTS.mdをまとめて反映し、.github/workflows/windows.ymlはActions v6版を使用してください。エンジン本体・モデルの再取得は不要です。
