# Go棋譜Studio / GoKifuStudio

**GoKS-v.1.0（内部バージョン1.0.0）**

Windows PC向けの棋譜編集・KataGo解析・対局アプリです。日本語／英語、通常表示／シンプル表示に対応します。実行ファイル名は `GoKS.exe` です。

## 起動

Windows用ZIPをすべて展開し、`GoKS.exe` を起動します。エンジンは同梱していません。棋譜編集と人間同士の対局はエンジンが無くても使えます。

「エンジン」メニュー先頭の「CPU版エンジンを自動セットアップ」を選ぶとKataGo(CPU)を登録できます。確認後、GoKS.exeの隣のkatagoフォルダーへKataGo Eigen v1.18.1とモデルを取得・配置します。各工程の進行状況が表示され、完了するとエンジンリストへ自動登録されます（「リストに追加」は不要です）。既存のkatagoフォルダーがある場合はバックアップを保存してから入れ替えます。保存できない場合はGoKSを自分が書き込める場所へ移すか、手動登録を選んでください。

CPU版エンジンは固定で、自動更新しません。エンジンを更新するにはKataGo公式リリースから新しいWindows版ZIPを入手し、既存のkatagoとは別のフォルダー（例：katago-new）に展開します。使うモデル（拡張子.gzのファイル）をその中のmodelsに置き、「エンジンリスト」で別名登録してください。モデルだけ更新する場合は公式モデル一覧からNetwork Fileを入手し、元のモデルとは別名でmodelsに置きます。「新規」でエンジン(katago.exe)と新しいモデル（拡張子.gzのファイル）を登録します。

[KataGo releases](https://github.com/lightvector/KataGo/releases) · [KataGo networks](https://katagotraining.org/networks/)


「エンジン」から「個別ダウンロード」を開きます。「CPU版エンジンを入手」でKataGo Eigen v1.18.1を入手したらZIPを展開します。「CPU版モデルを入手」で取得した.gzを解凍せず、そのフォルダーまたはmodels内に置きます。エンジンリスト下の「新規」から「エンジンの名前」を記入、「エンジン」「モデル」「設定CFG」を欄の右端にある「参照」から指定してください。記入・指定されたら「リストに追加」を押します。「設定CFG」は空欄でも構いません。エンジン名右の「起動時」ラジオボタンにチェックするとGoKS.exeの起動時に自動起動します。

[CPU版エンジン](https://github.com/lightvector/KataGo/releases/download/v1.18.1/katago-v1.18.1-eigen-windows-x64.zip) ／ [CPU版モデル](https://media.katagotraining.org/uploaded/networks/models/kata1/kata1-b10c128-s1141046784-d204142634.txt.gz)

使い方は同梱の **Manual.html** を開いてください。日本語・英語を切り替えられます。

このZIPがソース版の場合、実行ファイルは含まれません。GitHub ActionsでWindowsビルドを実行し、生成された `GoKS-v.1.0` のArtifactsを取得します。Releasesの利用者向けZIPとGitHub自動生成の「Source code」は区別してください。

## 機能

- 棋譜の閲覧・編集、変化、コメント、置碁・自由置碁、盤上の記号。
- 棋譜・画像のファイル読み込み、ドラッグ、クリップボードからの取り込み。
- KataGoによる局面・全局解析、読み筋、グラフ、目数／勝率ランキング。
- 人間対AI・AI対AI・人間対人間の対局、中断・再開・待った。
- 推定値、終局後の地合い計算。
- 棋譜・解析結果の保存、盤面画像・印刷、手順GIF、一時保存。
- 文字・盤面・背景・グラフ・石音の変更。

## 文字・外観・音

左パネルの「表示・音」、またはシンプル表示の「表示」→「表示・音」で独立した設定窓を開きます。設定窓は移動・サイズ変更が可能です。

| 設定 | 範囲 |
|---|---|
| 通常文字 | 小12／標準14／大16／特大18px |
| 見出し・主要項目 | 14／16／18／20px |
| 補助表示 | 12／12／14／16px |
| 通常ボタンの高さ | 24／26／28／30px、内側余白3px |
| フォント | 端末内のフォント名を選択・入力 |
| 盤上の数字・記号 | 80／100／120%、盤面の大きさに連動 |
| テーマ | 木肌・白灰・夜。色の個別変更も可能 |
| 盤面・石 | 無地・木目・画像、立体・単色・画像 |
| グラフ | 色、線幅1～4px（0.5px刻み）、実線・破線 |
| 石音 | 独自合成音3種またはWAV、音量0～100% |

日本語と英語の文字サイズ・フォントは別々に保存します。大きな文字では折り返しやスクロールが増える場合があります。存在しないフォントは標準フォントで補います。フォントファイルは配布しません。

設定変更はプレビューされます。「元に戻す」または「閉じる」で未保存の変更を戻します。「標準に戻す」は現在の項目だけを戻し、他の項目の設定を維持します。「文字」は現在の言語と盤上の数字・記号が対象です。変更を確定する場合は「保存」を押します。着手・手順移動・自動再生の石音は個別に指定でき、読み筋へのマウスオーバーは無音です。

Windowsのインストール済みフォント一覧から選ぶか、フォント名を入力してEnterを押します。一覧を取得できない場合も手入力できます。黒白の石は立体・単色・画像ごとに3種の見本から選べ、自分の画像も登録できます。木肌テーマには薄い木目が付き、碁盤色を維持します。「画面の余白色」は本体の余白、「パネル背景」はパネルに適用されます。

画像はPNG/JPEG/WebP・8MB以下（最大512pxへ縮小して保存）、音声はWAV・1MB以下です。環境によってはユーザー操作前に音が再生できない場合があります。

碁盤画像を取り込むと模様は自動で「画像」になり、WAVを取り込むと石音は「WAVファイル」になります。選択したファイル名も保存します。WAVの解除では標準の石音に戻ります。

グラフの下部は手数の数字のみを表示します。重ならないよう目盛りの文字を間引き、25手ごとの短い線と最終手数は残します。空盤など表示範囲が極端に狭い場合は表示可能な数を優先します。

## エンジンと対局

エンジンリスト右端のラジオボタンにチェックしたエンジンを起動します。登録件数の右の↑／↓は選択中のエンジンを移動します。起動指定の登録やファイルが見つからない場合は警告を表示します。初回は未登録です。

「新規対局（対局者・条件）」で対局を設定します。開始前は設定と操作欄を一緒に畳めます。開始後は操作欄と、黒・白の対局者名、互先／置碁の子数、コミを枠内に表示します。中断・待ったでは対局しているKataGoを再利用します。中断可能な探索命令に未対応の旧版は、思考中のみ再起動が必要です。

人間対KataGoのグラフの目数差は黒視点です。AI同士では勝率・目数差とも各AIの自分視点で表示します。シンプル表示への切替と通常表示への復帰は、棋譜や対局を維持します。「キー操作」は左パネルから確認できます。

## 人間用の対局時計

対局設定の人間側にある「方式」で、切れ負け・秒読み・フィッシャー・カナダ・無制限の順に5方式を選べます。AIには従来どおり時間・訪問数の上限を適用します。

| 方式 | 入力欄と初期値 | 動作 |
|---|---|---|
| 切れ負け | 持ち時間（分）30 | 時間を使い切ると負けです。 |
| 秒読み | 持ち時間（分）30、秒読み（秒／回）30／5 | 持ち時間終了後に秒読み。時間内の着手で現在の1回分を戻し、使い切るたびに回数を減らします。最後の回も使い切ると切れ負けです。 |
| フィッシャー | 持ち時間（分）30／加算（秒／手）10 | 合法な着手・パスの完了ごとに10秒加算します。時間が切れると負けです。上限は設定していません。 |
| カナダ | 持ち時間（分）0／区間（分）10／手数15 | 初期値は最初から10分以内に15手。15手打つごとに次の10分・15手へ戻り、余った時間は繰り越しません。最初の持ち時間を設定すると、その終了後に区間制へ移ります。 |
| 無制限 | 入力なし | 時間切れによる負けはありません。 |

入力欄は方式ごとに必要なものだけを原則1行で表示します。秒数と回数は「30／5」のように並べます。さらに狭い幅や大きな文字では、重ならないよう折り返します。秒読みの持ち時間0は最初から秒読み、回数0は持ち時間のみです。

対局開始時に独立した時計窓が開きます。「対局時計」で再表示できます。窓を閉じても計時は続きます。中断・推定値の計算・着手確認中は停止します。「待った」では消費時間を返さず、取り消した手による加算時間・区間更新も取り消します。結果として時間が尽きれば切れ負けです。

秒読みは毎秒音が鳴り、残り1秒と最後の1回では音を強めます。他の方式では残り10秒から警告音を鳴らします。時計窓の「警告音」で消音できます。
