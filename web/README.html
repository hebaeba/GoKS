この碁盤について

棋譜の編集・解析・保存

  • 「棋譜をロック」をオンにすると、誤クリックによる棋譜の変更を防げます。石や記号を編集するときはロックを解除してください。
  • ４路から19路までの碁盤を選べます。置碁は「置碁の設定」で指定できます。
  • 途中から別の手を打つと変化になります。「ここへ挿入」で手順の途中に手を追加できます。変化の削除や本譜への変更もできます。
  • 盤上の石をクリックすると、その手を打った局面へ移動します。赤いスライダーや「指定手数へ移動」でも移動できます。
  • 「自動►」で手順を再生できます。「手数の表示」や直近５手の表示を選べます。
  • 「手番切り替え」で次の黒番・白番を切り替えます。
  • 盤面を回転すると、その向きで棋譜・盤面画像を保存します。本譜・変化・配置石・記号・文字の位置も回転します。
  • 棋譜読込みはSGF・NGF・UGF・UGI・GIB・MGTに対応しています。文字コードは通常、自動判定します。ファイルのドラッグや棋譜テキストの貼り付けでも読み込めます。保存はSGF形式です。
  • 「画像から」で写真や盤面図の石を認識できます。配置を確認・修正し、置き石・コミ・次の手番・取られた石を入力してください。着手順・コウ履歴は復元しません。部分図の外側は未確認です。
  • KataGoによる局面解析・全局解析に対応します。スペースキーで局面解析を開始・停止します。候補手へのマウスオーバーで読み筋を表示し、クリックまたはF2で候補手を着手できます。文字入力中やダイアログ表示中はショートカットを抑制します。
  • 「網掛け領域内だけ解析」は、網掛けされた部分のみ解析します。外側の石は残し、候補手と読み筋の着手先を網掛け内に限定します（パスは可能です）。評価値は全局の評価です。対象の石と周囲の空点を含めて指定してください。死活の正解を保証する機能ではありません。
  • 「勝敗判定」は日本ルール・中国ルールに対応します。手入れを終えた盤面で、死に石とセキを指定してください。死活は自動判定しません。
  • 棋譜全体、本譜のみ、コメントを除いた本譜を保存できます。盤面画像はPNG・JPG、手順はGIFで保存でき、盤面の印刷にも対応します。
  • 一時保存は、この端末のブラウザーまたはアプリ内に１件を上書き保存します。自動保存をオンにすると編集が落ち着いた後に保存します。終了後も残りますが、他の端末とは共有しません。大切な棋譜は「保存・印刷」からSGFファイルに保存してください。

画像取り込みの初期値

置き石は0〜9の選択式で、0が初期値です。コミは「−／＋」で0.5ずつ増減でき、直接入力もできます。全19路盤はコミ6.5、部分図・その他の路数は0です。置き石を1〜9にすると白番・コミ0.5に切り替わります。コミと手番はその後に手動変更できます。取られた黒石は白のアゲハマ、取られた白石は黒のアゲハマです。アゲハマの開始値は独自SGF項目で保存するため、他のソフトでは無視される場合があります。

画面操作

中央の仕切りをドラッグすると碁盤とメニューの幅を調整できます。仕切り上部の赤丸で標準幅へ戻ります。スマホ幅では縦に並びます。

候補手の青色は最有力候補、金枠と「実・順位」は実戦の次の手です。候補手にマウスを重ねている間は読み筋が表示され、外すと元の局面に戻ります。エンジン名をクリックすると登録済みのエンジンを選べます。「終了」はエンジンを終了し、「解析を停止」はエンジンを残して解析だけを止めます。

対応範囲

KataGoの実行にはWindows版またはローカル接続環境が必要です。スマホ単独では棋譜編集と保存済み解析の閲覧を利用できます。画像の石の認識は誤りがあり得るため、必ず確認してください。写真から着手順を復元する機能はありません。
