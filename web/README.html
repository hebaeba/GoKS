このGo棋譜Studioについて

棋譜の編集・解析・保存

  • 「棋譜をロック」をオンにすると、誤クリックによる棋譜の変更を防げます。石や記号を編集するときはロックを解除してください。
  • ４路から19路までの碁盤を選べます。置碁は「置碁の設定」で指定できます。
  • 途中から別の手を打つと変化になります。「ここへ挿入」で手順の途中に手を追加できます。変化の削除や本譜への変更もできます。
  • 盤上の石をクリックすると、その手を打った局面へ移動します。赤いスライダーや「指定手数へ移動」でも移動できます。盤面上でホイールを手前に回すと１手進み、逆回転で１手戻ります。↓キーで１手進み、↑キーで１手戻ります。入力欄や説明窓では手順移動を行いません。
  • 「自動►」で手順を再生できます。「手数の表示」や直近1・2・3・5・10・20・30・50手、または指定した手数の表示を選べます。
  • 「手番切り替え」で次の黒番・白番を切り替えます。
  • 盤面を回転すると、その向きで棋譜・盤面画像を保存します。本譜・変化・配置石・記号・文字の位置も回転します。
  • 棋譜読込みはSGF・NGF・UGF・UGI・GIB・MGTに対応しています。文字コードは通常、自動判定します。ファイルのドラッグや棋譜テキストの貼り付けでも読み込めます。保存はSGF形式です。手順・配置・記号がない空の棋譜は保存できません。開始局面が空でも後続の手順があれば保存できます。
  • 「画像から」で写真や盤面図の石を認識できます。配置を確認・修正し、置き石・コミ・次の手番・取られた石を入力してください。着手順・コウ履歴は復元しません。部分図の外側は未確認です。
  • KataGoをGTP方式で起動し、局面解析・全局解析を行います。スペースキーで局面解析を開始・停止します。候補手へのマウスオーバーで読み筋を表示し、クリックまたはF2で候補手を着手できます。文字入力中やダイアログ表示中はショートカットを抑制します。
  • 「網掛け領域内だけ解析」は、網掛けされた部分のみ解析します。外側の石は残し、候補手と読み筋の着手先を網掛け内に限定します（パスは可能です）。評価値は全局の評価です。対象の石と周囲の空点を含めて指定してください。死活の正解を保証する機能ではありません。
  • 「地合い計算」は日本ルール・中国ルールに対応します。手入れを終えた盤面で、死に石とセキを指定してください。死活は自動判定しません。
  • 棋譜全体、本譜のみ、コメントを除いた本譜を保存できます。盤面画像はPNG・JPG、手順はGIFで保存でき、盤面の印刷にも対応します。
  • 一時保存は、この端末のブラウザーまたはアプリ内に１件を上書き保存します。自動保存をオンにすると編集が落ち着いた後に保存します。終了後も残りますが、他の端末とは共有しません。大切な棋譜は「保存・印刷」からSGFファイルに保存してください。
  • 「エンジン」メニューでは、実行ファイル・モデル・GTP用cfgを登録します。登録名を上下へドラッグするか↑↓で並べ替えられます。追加引数は詳細設定に１行につき１引数で入力します。gtp・モデル指定・cfg指定は自動付加します。解析・対局はKataGo専用です。モデル・設定の参照ではすべてのファイルを選べます。
  • 「推定値」は解析用エンジンで現在局面の領域と目数差を約２秒間探索して推定します。エンジンの起動時間は別です。読込み棋譜でも利用できます。対局中に押すと対局用AI双方の思考を停止して中断し、人間同士でも解析用エンジンに任せます。確認後は「対局」の「再開」で続けてください。推定は確定地や自動死活判定ではありません。
  • シンプル表示の詳細メニューは独立窓で開き、本体の外へ移動・拡大縮小できます。「解析」から形勢バー・グラフ、「その他」から著作権・ライセンスを開けます。詳細窓の操作は本体と連動します。

KataGoとの対局

右側の「対局」で黒番・白番それぞれに人間または登録済みKataGoを選びます。両方をKataGoにすればAI同士で対局します。棋譜や配置がある場合は、盤面をクリアするか現在の局面から始めるか選べます。クリア時も路数とコミは維持します。現在の局面を使う場合はその盤面・手番・コミから開始し、置碁や棋譜の途中からも対局できます。AIの１手の思考時間は0.1・0.5・1.0・2.0秒、または指定（0.1秒以上）、または無制限です。AIは時間と訪問数の上限のどちらかに達すると着手します。訪問数の初期値は無制限です。必要な場合だけ上限を指定してください。CFGに上限があっても対局欄の指定を優先します。「対局を終了」の確認中は対局を止め、キャンセル時は中断状態から「再開」できます。人間は無制限・30秒・60秒・指定から選べます。制限は１手ごとで、中断中と着手の通信確認中は時計を止めます。時間切れは負けとなります。

対局中は解析用エンジンを停止し、誤編集・手戻りを防ぎます。「中断」でエンジンを終了し、同じ盤面なら「再開」できます。中断後に盤面を変更した場合は「対局開始」で始め直してください。２回連続のパスで終局し、既存の「地合い計算」で死に石とセキを指定します。AIの自動投了は、初期値では自身の勝率3.0％以下が自分の手番で３回連続した場合です。黒白別に数え、回復すると回数をリセットします。閾値と回数は変更でき、無効にもできます。投了・時間切れはSGFのREに記録します。「対局棋譜を保存」は実際に進めた手順だけを、対局者名・対局名・日付入りのSGFで保存します。「対局ログ（SGF）」で内容を確認できます。診断情報は「接続ログ」にあります。

同じエンジン登録を黒白に使う場合は１つのプロセスを共用します。異なる設定では２つを起動するため、その分のメモリーが必要です。対応端末はWindows PCです。

画像取り込みの初期値

置き石は0〜9の選択式で、0が初期値です。コミは「−／＋」で0.5ずつ増減でき、直接入力もできます。全19路盤はコミ6.5、部分図・その他の路数は0です。置き石を1〜9にすると白番・コミ0.5に切り替わります。コミと手番はその後に手動変更できます。取られた黒石は白のアゲハマ、取られた白石は黒のアゲハマです。アゲハマの開始値は独自SGF項目で保存するため、他のソフトでは無視される場合があります。

画面操作

全局解析の初期時間は１局面0.1秒（簡易）です。対局の起動中と終局時は黄色い結果欄で知らせます。終局後は結果欄をクリックすると強調色を解除でき、文章は残ります。

通常モードでは、棋譜を開く・画像から・保存／印刷などの操作を碁盤の左側にまとめています。「座標」のあり／なしで座標表示を切り替えられます。なしの場合は座標用の余白も盤面に使います。表示設定は次回起動時にも引き継ぎ、盤面画像にも反映します。棋譜データ自体は変わりません。

盤上の候補手の勝率・目数差は、初期設定では手番の側から見た値です。黒番なら黒視点、白番なら白視点です。表示設定で変更できます。全局グラフは選択した表示軸の説明に従います。エンジン登録リストは件数で折り畳まず、すべて表示します。対局欄にも自動で反映されます。

碁盤は画面の空きに合わせて自動で拡大・縮小します。「右側を隠す」で右側の解析などの欄を隠すと、さらに広く表示できます。「右側を表示」で戻ります。通常表示では棋譜タイトルの左にコメント・対局情報のボタン、右にコミを配置します。コメントや対局情報がある場合にボタンを表示します。対局情報は途中の手数でも表示できます。

候補手の青色は最有力候補、金枠と「実・順位」は実戦の次の手です。候補手にマウスを重ねている間は読み筋が表示され、外すと元の局面に戻ります。エンジン名をクリックすると登録済みのエンジンを選べます。「終了」はエンジンを終了し、「解析を停止」はエンジンを残して解析だけを止めます。

Windows版は通常・シンプルそれぞれのウィンドウサイズ・位置・最大化状態を記憶します。モニターや表示倍率が変わったときは現在の作業領域内に収めます。右側の表示・非表示も記憶します。初回はタイトルバーを含め高さ約980に収まるサイズ（Windowsの表示倍率に応じた単位）を基準とし、画面が小さい場合はさらに縮めます。

直近の手数の選択は盤面画像・印刷にも反映します。譜分けするときは表示局面を進め、必要な手数範囲を選んで印刷してください。全棋譜を自動分割して印刷する機能ではありません。

網掛けの一括配置

「網掛け」を選び、ドラッグで対象部分を隙間なく囲みます。その内側を右クリックすると、石のある交点も含めて内側全体を網掛けします。四角形でなくても利用でき、「取り消し」で一括操作前へ戻せます。囲みが途切れて盤端までつながる場合や、網掛け済みの交点を押した場合は塗りません。棋譜ロック中・対局中・地合い計算中は変更できません。「網掛け」以外のときは通常の右クリックメニューが開きます。

保存時のファイル名

Windows版の保存窓は、ファイル名の初期入力から拡張子を分けています。名前部分を入力すれば、選択されたファイルの種類に従って.sgfなどの拡張子が自動で付きます。ブラウザー版は利用するブラウザーの保存機能によって表示が異なる場合があります。

対局時計

人間側の方式は「切れ負け・秒読み・フィッシャー・カナダ・無制限」から選びます。秒読みの初期値は持ち時間30分・30秒／5回です。フィッシャーは着手ごとに時間を加算し、カナダは指定手数を打つと区間の時間を更新します。制限時間を使い切ると時間切れ負けになります。AIには対局設定の時間・訪問数制限を使います。

時計は移動・サイズ変更できる独立窓に表示します。Windowsでは本体の手前に置き、位置とサイズを次回も復元します。本体を最小化すると時計も隠れます。窓を閉じても計時は続き、「対局時計」で再表示できます。計時を止めるには対局を中断してください。秒読みの警告音は消音でき、最後の1回は音を強めます。

対応範囲

KataGoの実行にはWindows版またはローカル接続環境が必要です。この版はPC専用です。スマホ・タブレット版とKataGoを使わない棋譜編集専用版の公開は保留しています。画像の石の認識は誤りがあり得るため、必ず確認してください。写真から着手順を復元する機能はありません。

碁盤に戻る

シンプルモード

操作欄の「シンプル表示」で切り替え、「通常表示」で戻ります。棋譜・表示局面・解析状態は共有します。前回のモードを記憶します。

ウィンドウの大きさに合わせて碁盤が拡大・縮小します。Windows版ではシンプルモードのウィンドウ幅を碁盤に合わせ、通常表示へ戻すと元の幅に戻ります。上部はメニュー1行、下部は対局情報1行とラベルなしの手数スライダーです。長い対局者名は省略表示し、ホバーで確認できます。

右クリックで盤面の操作メニューを開きます。クリップボードからの読み込みはその中にあります。タッチ端末では上部メニューから操作できます。各詳細画面は「閉じる」で閉じます。

キーボード操作（通常・シンプル共通）

  • Home：初手へ移動（着手前の局面）、End：選択中の手順の最終手へ移動
  • Ctrl+Home：碁盤をクリア（確認あり。棋譜ロック中は無効）
  • M：手数の表示・非表示、C：座標の表示・非表示
  • O：棋譜を開く
  • Space：解析の開始・停止、F2：第一候補を着手
  • ↓：1手進む、↑：1手戻る。Shift+↓／Shift+↑：10手移動。マウスホイールを手前に回すと1手進み、奥に回すと1手戻ります
  • Del：表示中の着手以降を削除

文字入力・ダイアログ内では入力操作を優先します。キー一覧は通常モード最下部の「キー操作」、シンプルモードの「その他」にあります。

左側の形勢表示

横バーは現在局面の黒白の勝率です。グラフは黒の勝率（緑・左軸）と黒から見た目数差（マゼンタ・右軸）を表示します。目数差の正は黒優勢、負は白優勢です。未解析の局面は空白にし、連続する解析済み局面だけを線で結びます。クリックでその手数へ移動します。

置碁（HAが2以上）のAI自動投了は初期状態で無効です。対局中のチェック変更は即時反映し、変更後から連続回数を数えます。

パネルの幅と画像保存

通常表示では左右のパネル境界をドラッグすると幅を調整できます。幅は次回起動時にも保持します。境界のダブルクリックで標準幅へ戻ります。左側は初期330px、右側はメニュー文字が折り返さない幅を基準に決めます。右側を非表示にした状態やシンプル表示の切替でも設定は保持します。

「盤面を無色で保存」は白い盤面と黒白の石を、表示の2倍以上・最低1600×1600pxで描き直して保存します。画面の盤面色や棋譜は変えません。PNGは白黒2色、JPGは白黒の描画をJPEG圧縮した画像です。形式は画像保存のPNG/JPG選択を共用します。

網掛けの境界に盤端を使えます。網掛けツール中に右クリックした側の連続する空間を塗ります。石がある交点も含みます。反対側を右クリックした場合は反対側を塗ります。取り消しで元へ戻せます。

対局中の評価も左グラフに蓄積します。KataGoへの指定で黒視点に統一しているため、白番側の評価を二重に反転しません。グラフは緑が黒勝率、マゼンタが黒から見た目数差です。未解析部分は空白で、離れた結果を線でつなぎません。対局を進行中のグラフクリックによる手数移動は無効です。中断・終局後に参照できます。

作業のリセットと対局条件

碁盤をクリアすると、網掛けなどのツール選択・自動再生・解析・画像プレビューを終了し、通常の着手へ戻ります。棋譜は「取り消し」で戻せますが、終了した解析・再生は自動再開しません。登録エンジンや表示設定、一時保存データは消しません。

AIの時間制限は無制限・0.5・1.0・2.0・5.0・10秒・指定から選べます。時間と訪問数のどちらかに達すると着手します。両方を無制限にすると着手を待ち続ける場合があります。自動投了は初期値で自身の勝率3.0％以下が自身の手番で3回連続、序盤の投了禁止は初期値0手（禁止なし）です。序盤の禁止手数は変更でき、0なら禁止なしです。相手の手番中は思考しません。

画像取り込み窓は見出しをドラッグして移動、右下の角でサイズ変更できます。Windows版の保存先は起動したEXEのあるフォルダーが初期位置です。

初回起動は碁盤の実寸に合わせて余分な縦幅を縮めます。次回からは保存したウィンドウサイズ・最大化状態を優先します。幅が狭く高さが大きいウィンドウや最大化では、正方形を保つため碁盤下に余白が生じることがあります。

表示・音

通常表示の左パネル「表示・音」、シンプル表示の「表示」→「表示・音」で設定窓を開きます。文字・碁盤背景・グラフ・石音の4項目です。変更はプレビューされ、適用で保存、「元に戻す」または窓を閉じると最後の保存内容へ戻ります。「標準に戻す」は現在の項目だけを戻します。「文字」は現在の言語の文字設定と盤上の数字・記号が対象です。保存には「適用」が必要です。

文字と外観の範囲

文字は小12px・標準14px・大16px・特大18px。見出しは各2px大きく、補助表示は12／12／14／16pxです。日本語・英語のサイズとフォントを別々に保存します。盤上の数字・記号は80／100／120%。テーマ、色、模様、石の描画、グラフ線を選べます。大きい文字では折り返し・スクロールが増えることがあります。

画像と石音の登録

画像はPNG/JPEG/WebPの8MB以下、保存時に最大512pxへ縮小します。音声はWAVの1MB以下です。音量0は無音です。着手・手順移動・自動再生ごとにオンオフを選びます。読み筋のホバーでは鳴りません。独自の石音3種は合成音で、LizzieYzyの素材を使用していません。
