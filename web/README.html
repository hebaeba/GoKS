棋譜編集ツール 単独版（更新17）

KataGo解析

エンジン接続後「解析を開始」またはスペースキーで、現在の局面を時間制限なしで解析します。着手・手戻り・変化の切り替えに追従します。「解析を停止」またはスペースキーで停止します。エンジンの接続は維持するので、そのまま再開できます。

通常の設定欄には「ルール」「読み筋の表示手数」「訪問数」を表示します。訪問数は現在の局面に対するKataGoの総訪問数です。個々の候補手の訪問数とは異なります。新しい解析要求の開始時は0とし、結果が届くたびに更新します。停止後や保存済み結果を開いたときは、その結果の値を表示します。

全局グラフを作る場合は「全局解析・時間設定」を開き、１局面の時間を選んで「全局解析を開始」を押します。0.1秒・0.5秒・1秒・3秒・5秒、または指定時間を使えます。時間設定は全局解析だけに適用され、通常の連続解析を制限しません。全局解析も上の「解析を停止」またはスペースキーで止められます。

エンジン・モデル・設定の「参照…」でファイルを選べます。起動できないときはエラー欄と接続ログを確認してください。「候補手の表示設定」で盤上の表示数（非表示・5・10・20・50・100手・無限大）、2列／3列、数値の視点を変更できます。無限大はKataGoが返した全候補を意味します。初期値は5手・2列・黒視点です。

青は推奨1位、ほかの色は1位との目数評価差で緑（0.5目以内）・黄（2目以内）・オレンジ（2目超）です。色は確定した善悪ではありません。金枠は実戦の次の手です。盤上の候補手と一覧の着点にマウスを重ねると読み筋を表示します。元の棋譜は変更されず、保存画像にも一時表示を混ぜません。クリック／タップすると編集に切り替え、その１手を着手します。

読み込み・保存

「棋譜を読み込む」の上向きメニューで「ファイルから」「棋譜欄から」「文字化けする場合」を選べます。SGF・NGF・UGF・UGI・GIB・MGT（SGF形式）に対応します。ファイル・棋譜欄から読み込むと最終手を表示します。掲示板記事の指定手数は優先します。ファイルの読込みでは棋譜欄を書き換えません。UGIのReviewNode形式の変化・コメントにも対応しています。

文字コードはSGFのCA指定、UTF-8、形式別の既定値を使います。UGF/UGIはShift_JIS、NGF/GIBは韓国語系、旧GI型NGFや中国版GIBはGB18030を試します。自動判定は万能ではないため、文字化け時は文字コードを選び直してください。

暗号化UGF、配信先だけのUGI、置碁入りの旧GI型NGF、GIBのSKIパス記録などは読み込まず、エラーを表示します。1ファイル1局、2MB、4～19路、20,000局面、SGFの入れ子128段までです。

上部の「保存・印刷」で「棋譜を保存…」「盤面を印刷…」「その他の保存…」を選びます。「棋譜を保存…」は変化・コメント・対局情報を含む棋譜全体をUTF-8のSGFで名前を付けて保存します。ブラウザー版の保存先指定方法は、ブラウザーの対応と設定に従います。「その他の保存…」では本譜だけ、コメント・局面名を除いた本譜、盤面のPNG/JPG、手順のGIF、一時保存を操作できます。本譜保存は選択中の変化ではなく、各分岐の先頭の手順を対象にします。

「盤面を画像保存」はPNG/JPGを選べ、表示中の碁盤と同じピクセル寸法で保存します。「盤面を印刷」は別窓でブラウザーの印刷画面を開きます。「手順をGIF画像保存」は現在選択中の手順を対象に開始・終了・間隔・縮尺・繰返しを指定します。最大500局面・50MB。作成後「GIFを保存」を押してください。手順や表示を変更したときは作り直します。

勝敗判定

「手番切り替え」の右の「勝敗判定」を押すと死に石判定等の別窓が開きます。元の碁盤の死に石をクリックすると一団を除いて再計算し、もう一度押すと解除します。判定中は局面の移動・編集を止めます。元の棋譜・コメント・着手番号は変更しません。

日本ルールを初期値とし、「中国ルール」で切り替えます。日本ルールは地から相手に取られた石と自分の死に石を引く方式、中国ルールは活き石と囲んだ空点を足す方式です。置碁では白にコミを加えます。

「計算条件・アゲハマとセキ」の下に黒・白が取った石、中国ルールの置石補正、セキ指定を配置しました。セキに関係する両色の一団を指定してください。日本ルールでは指定された一団に接する空点を地から除外します。中国ルールでは片方だけに囲まれた空点を数えます。

「再計算」は死に石・セキ指定を解除します。入力したコミ・アゲハマなどは維持します。「閉じる」は別窓の最下行中央です。

死活や特殊なセキを自動で判定する機能ではありません。ダメ詰め・手入れを終え、死に石・セキ・アゲハマを確認してください。途中図・配置石で編集した盤面・不正な着手を許容した棋譜では特に計算条件の確認が必要です。

別窓は最前面に表示するようにしていますが、ブラウザーによっては通常の窓になります。必要に応じてドラッグしてください。

盤面の一時保存・復元

棋譜欄下の「盤面の一時保存・復元」に「自動で一時保存」「今すぐ保存」「復元」「保存を削除」があります。自動保存は一定間隔ではなく、編集が止まって約0.7秒後です。挿入中・勝敗判定中は一時保存しません。

棋譜全体、選択した変化と局面、棋譜欄、未反映のコメント・対局情報をこのブラウザー内に1件保存します。前回または他の画面の保存がある場合は、勝手に上書きせず「復元」または「今すぐ保存」を待ちます。復元は現在の棋譜を置き換えるため確認します。説明欄の開閉状態は保存しません。

サーバーへの送信・端末間共有は行いません。プライベートモードやデータ削除、容量制限、ローカルファイルの移動などで利用できなくなる場合があります。一時保存だけに頼らず、大切な棋譜はファイルに保存してください。

候補手と連続解析

候補手にマウスを重ねると、同じ碁盤上に読み筋をまとめて一時表示します。マウスを外すと元に戻ります。棋譜データは変更しません。候補手のクリック／タップは、閲覧モードでも編集に切り替えてその１手を着手します。読み筋全体を棋譜に追加する操作ではありません。既存の続きとは異なる手なら変化として残します。

「解析を開始」で時間制限のない連続解析を開始します。全局を順に調べる操作だけは「全局解析・時間設定」にまとめています。

スペースキーで連続解析の開始・停止を切り替えられます。停止してもエンジンの接続は維持します。入力欄・ボタン・メニュー・ダイアログの操作中は、その操作を優先します。碁盤にフォーカスがある場合は、エンジン接続中のスペースキーは解析切替、Enterは着手です。

連続解析の保存対象は現在選択中の手順です。分岐を切り替えると、共通の履歴の結果だけを引き継ぎます。残したい別手順の解析は、切り替える前にファイルへ保存してください。

編集と変化

閲覧では通常の盤面クリックで着手できません。ただし解析候補手のクリックは、編集に切り替えて着手します。編集で着手・パス・削除・記号の配置ができます。「ツール」内の＊印はドラッグで連続操作できます。文章入力は10px・青色・横書きです。コメント・対局情報は入力後に「反映」を押します。

途中から異なる手を打つと元の続きを残して変化を作ります。変化記号は分岐手数順に振り直し、表示行は重ならない区間をまとめます。「変化1」などの行ボタンは同じ行の次の分岐へ移動し、最後の次は最初です。「この変化を本譜に」「この変化を削除」は選択中の変化を対象とし、取り消し可能です。

スライダーは棋譜全体の最大手数を共通目盛りとします。短い変化の終端を超えて動かしたときは、その変化の最後で止まります。盤上の石・丸数字・数字入力からも移動できます。

「ここへ挿入」で現在の手の後に新しい手を追加し、「終了する」で元の続きをつなぎます。奇数手の挿入は手番の連続を確認します。元の続きに不正な着手が生じた場合、その手への移動時に、許容・以降削除・移動中止を選べます。

通常の着手は石の取り上げ、自殺手、単純コウを検査します。スーパーコウや対局規定全体を再現するものではありません。対局情報で設定したルールは情報として保存し、着手検査を切り替えません。

掲示板への投稿容量

画像は1枚300KB（307,200バイト）まで、最大3枚です。投稿全体の初期上限は1MB（1,048,576バイト）で、画像・棋譜・本文・フォームの送信情報を含みます。設置者はinit.cgiのmaxdataで投稿全体の上限を変更できます。現在の上限は掲示板の投稿フォームと留意事項で確認してください。碁盤単体の棋譜読込み上限とは異なります。

データと実装

SGFの未知プロパティは保持します。独自プロパティXIGPENDING／XIGFORCEは挿入後の確認状態、XIGTEXTは文章の表示指定です。他ソフトでは解釈されない場合があります。

この碁盤はEidoGoのコード・画像に依存しない独立実装です。ソースは実行ファイルと同じで、外部CDN・外部サービスの通信APIは使いません。掲示板接続では、同じサイトのCGIから記事の棋譜を取得し、指定手数を表示します。掲示板側の投稿フォームから、碁盤や棋譜欄の内容を取り込めます。「自動►」で現在の局面から選択中の手順を1〜5秒間隔で再生できます。終端で自動停止します。手動操作や別タブへの移動でも停止します。
