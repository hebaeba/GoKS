Source and Implementation

The board is an independent implementation using no EidoGo executable code, images or player folder. Its unminified JavaScript is the source, located in web in this standalone edition.

  • engine.js: move handling and Go rules.
  • sgf.js・import.js: SGF and other record imports.
  • score.js: scoring.
  • export.js: image, GIF and record exports.
  • app.js: interface and editing.
  • forum-bridge.js: bulletin-board record loading.
