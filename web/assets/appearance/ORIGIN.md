# 独自素材 / Original assets

Go棋譜Studio用に新しく手続き生成したSVG模様・色パレット・石音です。LizzieYzy等の素材・録音・フォントは使用していません。
WAVは減衰振動と固定シードの雑音による合成音（44.1kHz / mono / PCM16）です。
generate_assets.pyは生成手順、preview.htmlは素材の試聴・確認用です。アプリは模様をCanvasで描画し、WAVを石音に使用します。
新規素材には本体のLICENSE.txtの非商用条件を適用します。
These newly generated assets use the application's noncommercial terms. No LizzieYzy recordings, textures or fonts are included.
